# 🐾 Виртуальный питомец

Сервис виртуального питомца реализрован в виде HTTP сервера с RESTful API. Он позволяет создавать питомцев, взаимодействовать с ними и отслеживать их состояние.

## 📌 Возможности

- Создание виртуального питомца с заданными именем и уровнем жизни.
- Взаимодействие с питомцем: кормление, поглаживание, угощение, прогулка и игнорирование.
- Изменение характеристик питомца в зависимости от действий.
- Получение текущей статистики питомца.
- Обработка условий исчезновения питомца.

## 🐱 Характеристики питомца

Каждый питомец имеет следующие характеристики:

| Характеристика | Описание | Начальное значение |
|---|---|---|
| `name` | Кличка питомца | Передаётся при создании |
| `life` | Количество очков жизни | Передаётся при создании |
| `happiness` | Уровень счастья | `2` |
| `hunger` | Уровень голода | `2` |

## 🎮 Действия с питомцем

Каждое действие изменяет характеристики питомца.

| Действие | Счастье | Голод |
|---|---:|---:|
| `feed` — покормить | 0 | −2 |
| `pet` — погладить | +1 | +1 |
| `treat` — дать вкусняшку | +2 | −1 |
| `walk` — погулять | +1 | +3 |
| `ignore` — проигнорировать | −1 | +1 |

Изменения применяются к текущим значениям характеристик.

### Правила выживания

- Если после действия уровень голода превышает `5`, питомец теряет очки жизни.
- При повторных срабатываниях условия потери жизни штраф увеличивается на `1` относительно предыдущего штрафа.
- Если количество очков жизни достигает `0`, питомец исчезает.
- Если уровень счастья после действия достигает `0`, питомец исчезает.

После исчезновения питомец больше не может выполнять действия и предоставлять актуальную статистику.
